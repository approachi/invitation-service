# Invitation Service

REST API сервис для управления ограниченной регистрацией в игре через коды приглашений.

Задание: [docs/тестовое.pdf](docs/тестовое.pdf)

## Требования

- [Docker](https://docs.docker.com/get-docker/) и Docker Compose
- [Go 1.25+](https://golang.org/dl/) (для запуска тестов локально)
- [Make](https://www.gnu.org/software/make/)

## Запуск

**1. Клонируйте репозиторий:**
```bash
git clone <repo-url>
cd invitation-service
```

**2. Запустите сервис:**
```bash
make run
```

Команда собирает Docker-образ и поднимает приложение вместе с PostgreSQL. Схема БД и seed-данные применяются автоматически.

**3. Проверьте, что сервис работает:**
```bash
curl -v -X POST http://localhost:3000/api/v1/invitations/twitter-reg1 \
  -H "Content-Type: application/json" \
  -d '{"Email": "user@example.com"}'
```

Ожидаемый ответ: `HTTP 200`

**4. Остановка:**
```bash
make down
```

## Seed-данные

Следующие коды приглашений доступны из коробки:

| Код                | Макс. использований |
|--------------------|---------------------|
| `twitter-reg1`     | 500                 |
| `telegram-test`    | 100                 |
| `instagram-hello`  | 250                 |

## API

### Регистрация по приглашению

```
POST /api/v1/invitations/{code}
```

**Запрос:**
```json
{
  "Email": "user@example.com"
}
```

**Ответы:**

| Статус | Причина                                                                 |
|--------|-------------------------------------------------------------------------|
| 200    | Регистрация успешна                                                     |
| 400    | Невалидный email / неизвестный код / код исчерпан / уже зарегистрирован |
| 500    | Внутренняя ошибка сервера                                               |

Все тесты:

Интеграционные тесты (автоматически поднимают отдельную тестовую БД):

## Make-команды

| Команда                 | Описание                              |
|-------------------------|---------------------------------------|
| `make run`              | Собрать и запустить все сервисы       |
| `make down`             | Остановить все сервисы                |
| `make build`            | Собрать бинарник в `bin/`             |
| `make test-unit`        | Запустить юнит-тесты                  |
| `make test-integration` | Запустить интеграционные тесты        |
| `make test`             | Запустить все тесты                   |
| `make db-conn`          | Подключиться к локальной БД           |
